## Overview
This project is a web application that includes features for chatbot creation, game playing, and user management. It allows users to build chatbots, play games, and access admin tools if they have the appropriate role. The application also includes features like user registration, login, profile editing, and password management.

- **Languages:** Python, HTML, CSS, JavaScript
- **Frameworks:** Flask
- **Libraries:** OpenAI API, JWT, SQLAlchemy, WTForms, Pillow

## Purpose of the Project
The project aims to provide a platform where users can interact with chatbots, play games, and manage their accounts. It also includes an admin section for managing users and sending newsletters.
